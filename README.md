# AI Data Analyst Agent

A context-aware AI data analyst agent that combines data analysis, AI agents, persistent memory, and context engineering.

## Project Goal

The goal of this project is to build an AI system that can:

- Analyze structured datasets using Python
- Understand natural-language questions about data
- Select and use analytical tools
- Remember useful information across sessions
- Retrieve relevant context when needed
- Learn from previous interactions
- Improve its memory through an out-of-band "dreaming" process
- Eventually run as a cloud-based application

## Technology

- Python
- Pandas
- LLM API
- Git & GitHub
- Streamlit
- Cloud platform

## Status

🚧 Project in development

This project is being built incrementally to explore practical applications of AI agents, context engineering, memory systems, data analysis, and cloud deployment.
